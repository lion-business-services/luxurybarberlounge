# Luxury Barber Lounge Release V11.4

This release adds Rubén Diaz, Jr. as the canonical owner/master-barber profile, separates his public barber identity from authenticated owner authorization, adds responsive portrait delivery for all nine barbers, and replaces the normal privileged booking-catalog bootstrap with a privacy-safe public Supabase catalog RPC.

It preserves the approved public design and the existing Supabase-first booking, portal, queue, notification, and Square-adapter architecture.

Authoritative release details and validation limitations are recorded in `docs/FINAL_RELEASE_REPORT.md` and `release-manifest.json`.
