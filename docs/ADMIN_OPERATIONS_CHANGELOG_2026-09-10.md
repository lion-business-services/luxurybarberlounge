# Admin operations overhaul — 2026-09-10

This release introduces a unified live Queue workspace, dedicated Payment Tracking for walk-ins and appointments, a seven-day barber appointment calendar with availability/time-off context, and a database-level paid-before-completion guard for walk-ins.

The changes are additive to the existing booking, Square, webhook, commission, notification, and scheduled reconciliation systems. Existing financial and notification automation routes are not replaced.
