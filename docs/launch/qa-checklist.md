# QA Checklist

## Viewports

- 320, 375, 390, 430, 768, 1024, 1280, 1440, and 1920 pixels
- Portrait and landscape where applicable
- Touch, mouse, keyboard, reduced motion, 200% zoom, and slow network

## Public flow

- Navigation, language toggle, footer, and mobile actions
- Hero visible immediately
- Scroll-to-discover releases cleanly
- Service filters and service details
- Barber filters and profiles
- Booking request, validation, error, and development-mode labels
- Walk-in disabled/live states
- Contact, call, directions, policies, FAQ, journal, gallery lightbox
- No broken asset, dead link, technical configuration leak, or fake live claim

## Portals

- Production portal gate
- Demo banner when explicitly enabled
- Client, barber, reception, and admin navigation
- Empty, loading, error, and integration-unavailable states
- Mobile table alternatives and touch controls

## Accessibility

- Skip link, landmarks, headings, labels, errors, focus, dialogs, keyboard, contrast, reduced motion, and status announcements
