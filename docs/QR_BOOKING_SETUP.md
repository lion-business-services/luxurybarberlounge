# QR Booking Setup

Use only the business-owned canonical URL:

`https://theluxurybarberlounge.com/book`

Recommended trackable business-card URL:

`https://theluxurybarberlounge.com/book?utm_source=business_card&utm_medium=qr&utm_campaign=booking`

Never encode localhost, a Vercel preview, FormSubmit, Supabase, Square, or another provider URL. The route works without login, avoids homepage video, preserves session progress, uses large touch targets, supports autofill, and records attribution without personal data.
