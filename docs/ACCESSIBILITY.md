# Accessibility

Target: WCAG 2.2 AA practices.

Implemented patterns include semantic landmarks/headings, skip link, visible focus, keyboard navigation, accessible buttons/forms, status messages, OTP labels and paste/focus behavior, touch-sized controls, reduced-motion rendering, contrast-aware luxury palette, alt text, no hover-only essential actions, and no motion-only information.

Carousels and profile controls support keyboard/touch. Portal tables retain headings and horizontal containment. Errors should be announced and associated with controls. Test browser zoom, screen-reader navigation, reduced motion, color contrast, and keyboard-only flows before launch.
