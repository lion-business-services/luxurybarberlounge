# Operations test matrix

- Walk-in created → visible in Admin Queue.
- Walk-in created → visible on Queue Board.
- Walk-in active after entered time → remains visible.
- Walk-in unpaid → cannot complete.
- Walk-in cash paid → payment record created and queue stays active.
- Walk-in Square paid → payment reconciles and queue stays active.
- Paid walk-in completed → queue becomes terminal.
- Appointment unpaid → absent from admin appointment calendar.
- Appointment paid → present in admin appointment calendar and appointment payment tracking.
- Barber schedule/time-off → represented on calendar.
