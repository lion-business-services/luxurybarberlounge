# Barber Schedules

A bookable barber must be active, non-demo, published, eligible for the selected service, and have an active schedule at the location.

Schedules are stored by weekday and effective date. Breaks and approved time off are separate blocking records. Owner-managed schedules are never overwritten by catalog synchronization. A default business-hours schedule is inserted only when a verified live barber has no schedule.

Before launch, confirm each live barber's profile, services, working days, breaks, time off, staff user mapping, and optional Square team-member mapping.
