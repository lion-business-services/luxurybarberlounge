# Reception Portal

The reception workspace is touch-first and operationally restrained. It includes today’s schedule, client search/create, booking lookup/handoff, check-in, late/no-show states, walk-in creation, queue, assignment/reassignment, Who’s Next, wait estimates, contact actions, kiosk controls, queue pause, and manager escalation.

Queue actions call deterministic server rules and write assignment/status history. Reception users cannot access owner-only policy, role, credential, or reconciliation configuration.
