# Luxury Barber Lounge Release

This source package is prepared for the existing GitHub and Vercel project.

## Deploy

1. Replace or merge the repository contents, preserving the existing `.git` directory and Vercel project link.
2. Do not copy `node_modules` from another computer.
3. Run `npm ci`.
4. Run `npm run check`.
5. Copy approved values from `.env.example` into Vercel environment settings.
6. Keep credential-dependent feature flags disabled until each activation checklist passes.
7. Push to the deployment branch and review the Vercel Preview before promotion.
