# Luxury Barber Lounge Release V11.3

This release replaces the provisional barber roster and launch catalog with the final client-intake data, preserves the approved public design, standardizes all eight mapped portraits, and completes the Supabase-first booking/portal/queue release package.

Authoritative release details and validation limitations are recorded in `docs/FINAL_RELEASE_REPORT.md` and `release-manifest.json`.

The release intentionally does not claim live provider delivery, live production RLS verification, lint, semantic type checking, or a production build because external credentials and a working package registry are required for those gates.
